1. Goal

Project Goal

The project develops and estimates a structural model of intergenerational human capital formation using Swedish data. The model is designed to connect pre-birth endowments, parental time investment, financial transfers, bequests, education, and labor-market outcomes in one dynamic framework.

The empirical target is to decompose how different family resources shape human capital accumulation and later outcomes, then use the estimated model for counterfactual exercises.

2. Current Model

Current Model

This page records the current working model. It is intentionally explicit about provisional pieces: the timing, state space, and choice set still need to be finalized before the MATLAB solver should be treated as canonical.

Timing

The provisional timing uses four broad stages:

Period Stage Main state/outcome
\(t=1\) Basic education Early human capital and ability measures
\(t=2\) Upper secondary Track, study effort, child work, parental investment
\(t=3\) Young adulthood Tertiary enrollment, work, parental death/bequest risk
\(t=4\) Career Adult human capital and earnings

State

A compact state vector for child \(i\) at period \(t\) can be written as:

\[ s_{it} = \left( t,\, h_{it},\, e_i^f,\, e_i^m,\, e_{it}^c,\, \eta_i,\, z_{it} \right), \]

where \(h_{it}\) is human capital, \(e_i^f\) and \(e_i^m\) are father and mother education, \(e_{it}^c\) is child education or track, \(\eta_i\) is latent ability or endowment, and \(z_{it}\) collects demographics and institutional states.

Choices

The desired choice vector is broader than the current MATLAB prototype:

\[ d_{it} = \left( \ell_{it}^f,\, \ell_{it}^m,\, x_{it},\, m_{it},\, \tau_{it},\, b_{it} \right). \]

Here \(\ell_{it}^f\) and \(\ell_{it}^m\) are parental labor supply choices, \(x_{it}\) is child study effort, \(m_{it}\) is parental time investment, \(\tau_{it}\) is an inter-vivo transfer, and \(b_{it}\) is a bequest-related resource.

Current code status. The MATLAB prototype currently enumerates 12 terminal choices from father labor supply, mother labor supply, and a high/zero transfer. Study time, school track, enrollment, child work, and human-capital transitions are not yet implemented.

Flow Utility

The general period utility can be represented as:

\[ u_t(s_{it}, d_{it}) = \omega_p u_p(c_{it}^p, \ell_{it}^f, \ell_{it}^m, m_{it}) + \omega_c u_c(c_{it}^c, x_{it}, \ell_{it}^c) + \xi_t(d_{it}), \]

where \(c_{it}^p\) is parental consumption, \(c_{it}^c\) is child consumption, and \(\xi_t(d_{it})\) can capture taste shocks or choice-specific costs.

The current terminal-period code uses the simpler placeholder:

\[ u_4(y_p,y_c)=\log(y_p)+\log(y_c), \qquad V_T(y_p,y_c)=\alpha_p \log(y_p)+\alpha_c \log(y_c). \]

Human Capital Transition

The model needs a period-specific production function:

\[ h_{i,t+1} = g_t \left( h_{it},\, x_{it},\, m_{it},\, \eta_i,\, e_i^f,\, e_i^m,\, X_{it}; \theta_h \right) + \varepsilon^h_{i,t+1}. \]

A central open modeling decision is whether ability \(\eta_i\) should mainly shift baseline human capital, raise the productivity of investments, or both.

Dynamic Problem

Given the state, feasible choices, transition process, and terminal value, the household's recursive problem is:

\[ V_t(s_{it}) = \max_{d_{it}\in\mathcal{D}_t(s_{it})} \left\{ u_t(s_{it},d_{it}) + \beta \mathbb{E} \left[ V_{t+1}(s_{i,t+1}) \mid s_{it}, d_{it} \right] \right\}. \]
3. Current Estimation Procedure

Current Estimation Procedure

The current estimation plan is simulated minimum distance / Method of Simulated Moments. For each candidate parameter vector, the model is solved, simulated, summarized into moments, and compared to empirical moments from the data.

\[ \widehat{\theta} = \arg\min_{\theta} \left[ m^{data} - m^{sim}(\theta) \right]' W \left[ m^{data} - m^{sim}(\theta) \right]. \]
  1. Choose parameters. Start from a candidate vector \(\theta\), including utility, production, income, transfer, bequest, and shock parameters.
  2. Solve the model. Use backward recursion to compute value functions and policy rules.
  3. Simulate households. Draw shocks, apply policy rules, and generate synthetic life-cycle histories.
  4. Compute simulated moments. Construct moments using the same definitions as the empirical moments.
  5. Evaluate distance. Compare \(m^{sim}(\theta)\) with \(m^{data}\) using weighting matrix \(W\).
  6. Update parameters. Iterate until the objective is minimized and diagnostics are stable.

Moment Registry

The exact moment vector is still open. Candidate blocks include education, grades or ability measures, parental labor supply, transfers, bequests, young adult enrollment/work, and adult earnings by family background.
